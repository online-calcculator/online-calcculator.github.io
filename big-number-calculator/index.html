How to Use the Big Number Calculator

Enter a number in X and, for two-number operations, another in Y. You can enter long whole numbers, negative values, decimals, and scientific notation such as 23E18 (23 × 1018). Choose one of the 11 green operation buttons. The answer appears above the input form, with the original inputs retained so you can run another operation.

  1. Enter X and optionally Y. The √X, X² and X! buttons only use X.
  2. Set Precision to between 0 and 5,000 decimal places. This controls the displayed rounding of division, negative powers, and square roots, not the exactness of addition or multiplication.
  3. Click an operation. Use Copy to copy the digits, Save for a text file, or Clear inputs and result to start again.

Worked Examples

Large Integer Addition

With X = 23E18 and Y = 3.5E19, the exact result of X + Y is 58,000,000,000,000,000,000 (displayed without separators as 58000000000000000000). Neither number is converted to an imprecise JavaScript Number.

Decimal Division and Square Roots

For X = 1 and Y = 3, division at precision 5 returns 0.33333. For X = 2, √X at precision 5 returns 1.41421. An exact decimal such as 10 ÷ 4 is displayed as 2.5, without unnecessary trailing zeroes.

Factorials, GCD, and LCM

For X = 20, X! returns 2432902008176640000. For X = 48 and Y = 18, GCD returns 6 and LCM returns 144. The modulo operation uses truncation toward zero: −7 MOD 3 is −1.

What Precision Means

The calculator represents finite decimals as an integer coefficient and a base-ten scale, using BigInt. This preserves every digit for addition, subtraction, multiplication, integer powers and the supported exact remainder calculations. Division and irrational square roots cannot always be represented as finite decimals, so their displayed results are rounded half-up to at most the requested number of digits after the decimal point. Trailing zeros are removed for readability.

Practical limits protect your browser: inputs up to 100,000 characters, rendered answers up to 100,000 characters, precision up to 5,000 decimal places, integer powers with |Y| up to 100,000, and factorials through 10,000!. Very large intermediate computations can be rejected even if their final results would be small.

Frequently Asked Questions

Can I enter scientific notation?

Yes. 1.25e6 is 1,250,000, and 2.5E-3 is 0.0025. Use a period for the decimal separator and do not include commas in an input.

Why are large-number answers different from a regular calculator?

Many ordinary calculators rely on IEEE 754 floating-point arithmetic, which can lose integer precision beyond 15–16 decimal digits. This calculator uses base-ten coefficient arithmetic backed by JavaScript BigInt instead.

Can I use fractional exponents?

The X^Y button supports whole-number exponents, including negative ones. Fractional exponents are not supported; √X handles the square root case. Square roots of negative numbers and division by zero are not real-valued results here.

Does it have a reset button and can I save results?

Yes. Use Clear inputs and result to reset the form, Copy to copy the answer, or Save to download the answer as a text file. Calculations run locally on the page.
