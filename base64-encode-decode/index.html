How to Use the Base64 Encoder and Decoder

For text, enter your content, select a character encoding, and choose Encode to obtain Base64 or Decode to turn Base64 into readable text. Results appear directly below the action buttons. Use Copy or Download to save the output, or Clear to start again.

For files, select encode a file and upload any local file to obtain its Base64 text. To reverse this process, select decode a file, upload a file containing Base64, and choose whether its output is text or binary. For text, choose a character set. For images and other binary files, choose Binary or Image to download the original bytes. Image previews are available for supported formats.

How Base64 Encoding Works

Base64 treats data as groups of three bytes (24 bits), divides them into four six-bit numbers, and maps each number to a character in the alphabet A–Z, a–z, 0–9, +, and /. The equal sign (=) is used for padding when the last group has fewer than three bytes.

Base64 Length Formula

For a file of n bytes, standard padded Base64 contains 4 × ceil(n / 3) text characters, excluding any added line breaks. For example, 10 bytes become 16 Base64 characters. Larger input is typically about 33% bigger after encoding, before accounting for padding.

Character Encoding and Decoding

Text must first be represented as bytes. UTF-8 is the recommended default and supports text in virtually any language; UTF-16 and several legacy encodings are also offered for interoperability. Choosing the wrong encoding during decoding may produce incorrect characters or an error. For binary files, do not decode as text—select Binary or Image to preserve the original bytes.

Frequently Asked Questions

Is Base64 encryption?

No. Anyone with the encoded data can decode it. Base64 is a reversible representation of bytes, not a security or confidentiality technique.

Can I encode images, PDFs, and other files?

Yes. File encoding takes the original bytes and returns their Base64 representation. File decoding reconstructs those bytes and supplies a download, preserving the file data rather than converting it through text.

Does this calculator upload my files?

No. Conversions use the browser’s local JavaScript APIs. No content is sent to a conversion server by this calculator.

What is the maximum file size?

There is no fixed limit built into this calculator. Very large files still require browser memory to read and display their Base64 text; processing speed and available memory depend on the device.

Why does my decoded text look wrong?

The Base64 may represent binary data, use a different character encoding, or be corrupted. Try the correct character set or choose Binary or Image when decoding a file.

Reference Standards

Base64 follows RFC 4648, Section 4. Browser text character-set decoding uses the standard WHATWG Encoding Standard.
