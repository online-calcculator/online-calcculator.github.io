How to Use the Root Calculator

Use the Square Root section for √a, the Cube Root section for ∛a, or the General Root section to choose a positive whole-number index n. Enter the number under the radical (the radicand) and select Calculate. The answer appears directly above that form and beside the radical, with a power check.

Select Clear to empty an individual form. The save icon downloads the currently displayed result as a text file. Calculations run in your browser without sending input values to a server.

Root Formulas and Definitions

For a real number a and a positive integer n, its nth root b satisfies bn = a. For a positive radicand, this is equivalent to b = a1/n. The square root (n = 2) and cube root (n = 3) are common special cases.

Square root√a = a1/2√81 = 9 because 9² = 81

Even-index roots of negative numbers are not real. Odd-index roots of negative numbers are real and negative. For example, the fifth root of −32 is −2. This calculator reports real-valued roots and explains invalid real-domain inputs.

Estimating an nth Root by Hand

For a positive radicand a and a reasonable nonzero guess x, Newton's method refines an nth-root estimate using the iteration:

xnext = ((n − 1)x + a/xn−1) / n.

With n = 2, the expression simplifies to the familiar square-root update (x + a/x)/2. Repeating the step improves an estimate under suitable starting conditions. The calculator itself uses the browser's floating-point math functions, not a fixed number of hand-calculation iterations.

Frequently Asked Questions

Can I take the cube root of a negative number?

Yes. For example, ∛−27 = −3 because (−3)³ = −27. The same principle applies to any odd positive root index.

Why is there no real square root of a negative number?

Every real number squared is nonnegative. Negative numbers have square roots in the complex-number system, but this tool only calculates real-valued results.

Can the root index be a decimal or negative number?

This calculator uses the conventional positive whole-number index n. A fractional or negative exponent is a different calculation and is not accepted as a root index here.

How are results rounded?

Results are displayed to approximately 14 significant digits, matching the reference's typical presentation. Intermediate calculations use JavaScript double-precision floating-point arithmetic; extremely large, small, or close-to-boundary values may be subject to floating-point rounding.

Is the result always the only root?

No. This tool reports the principal nonnegative square root for a nonnegative number. For example, 9 has principal square root 3, while both −3 and 3 satisfy x² = 9. The cube root and other odd-index real roots are unique.
