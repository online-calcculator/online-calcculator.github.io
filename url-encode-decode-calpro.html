How to Use the URL Encode / Decode Tool

Enter text or a percent-encoded string in the box above. Select Encode to make the value suitable for a URL query parameter, or Decode to recover the original text. The converted text appears directly below the buttons with a Copy control. Select Clear to remove the input and result.

This tool operates entirely in your browser. It uses JavaScript’s built-in encodeURIComponent() and decodeURIComponent() functions, following the same algorithm as the reference tool. Leading and trailing whitespace is trimmed before conversion.

How URL Percent-Encoding Works

URL percent-encoding represents a byte as a percent sign followed by two hexadecimal digits, written %HH. A space becomes %20; a literal percent sign becomes %25. Unicode text is represented using UTF-8: for example, the Greek letter Ω becomes %CE%A9.

Worked example

Input: name=Zoë & city=New York

Encoded output: name%3DZo%C3%AB%20%26%20city%3DNew%20York

Decoding the result restores name=Zoë & city=New York.

Which characters stay unchanged?

The core URI standard, RFC 3986, defines the unreserved characters as letters, digits, -, ., _, and ~. The reference-compatible JavaScript encodeURIComponent() method additionally leaves !, ', (, ), and * unchanged. This tool intentionally uses the reference behavior rather than a stricter RFC 3986 variant.

Frequently Asked Questions

Should I encode an entire web address?

Usually not. This tool encodes a component such as a search term or a single query parameter value. If you enter a whole URL, its separators (including :, /, and ?) will also be escaped. Construct the URL first, then encode only the data values.

Does decoding treat + as a space?

No. A plus sign stays a plus sign. This follows decodeURIComponent(). In application/x-www-form-urlencoded form data, a plus sign may represent a space, but that is a separate convention. To represent a space with this tool, use %20.

Why does decoding sometimes fail?

A percent sign must be followed by two hexadecimal digits, and encoded bytes must form valid UTF-8 text. For example, %ZZ or an incomplete UTF-8 sequence cannot be decoded. The tool displays an error rather than silently modifying invalid input.

Is the text uploaded or stored?

No. The encoding, decoding, validation, and copying happen in the browser. This page does not need a network service to process the text.
