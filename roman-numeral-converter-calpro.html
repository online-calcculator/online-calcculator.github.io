How to Use the Roman Numeral Converter

Enter a positive whole number such as 63, or Roman numerals such as LXIII, and select Convert. The result appears directly above the input panel, with a breakdown of the calculation. Select Clear to remove that input and its result. Copy or save any successful conversion using the controls in its result heading.

For dates or lists, use the second converter. For example, 2026/11/05 converts to MMXXVI/XI/V. You can use a slash, hyphen, period, backslash, vertical bar or a space as a separator. Each component converts separately without changing its order or separator. This tool converts notation; it does not validate whether a calendar date exists.

Roman Numeral Rules and Formula

Read symbols from left to right. Add a symbol's value unless it comes immediately before a larger symbol, in which case subtract it. The conventional subtractive pairs are IV (4), IX (9), XL (40), XC (90), CD (400), and CM (900). Standard modern spelling uses no more than three consecutive I, X, C or M symbols; V, L and D are not repeated.

Example — convert LXIII to decimal: L + X + I + I + I = 50 + 10 + 1 + 1 + 1 = 63.
Example — convert 768 to Roman: 768 = 700 + 60 + 8; 700 = DCC, 60 = LX and 8 = VIII. Together: DCCLXVIII.

Some historical inscriptions use variant spellings, but this converter validates the usual modern forms. For example, enter IV rather than IIII.

Large Numbers and the Vinculum

The standard Roman numeral forms cover 1–3,999. For larger values, this calculator uses the vinculum (overline): each overlined symbol represents 1,000 times its regular value. Type an underscore immediately before each overlined letter. For example, _V represents 5,000 and _X represents 10,000. An overlined sequence can precede an ordinary remainder; the converter supports up to 3,999,999.

Roman Numeral Dates

Convert each date element independently. For example, 4 March 2025 written in year/month/day order is MMXXV/III/IV. In mixed notation you may also write dates such as III/4/2025; each piece converts individually. A leading zero (such as 05) is omitted in its Roman form because Roman numerals have no zero symbol.

Frequently Asked Questions

Can I convert zero, fractions or negative numbers?

No. Classical Roman numerals do not have a standard zero sign, and this converter accepts only positive whole numbers from 1 to 3,999,999.

Are lowercase Roman numerals supported?

Yes. For example, mcmxcix is accepted as MCMXCIX, meaning 1,999.

Why does the converter reject some readable Roman numerals?

To avoid ambiguity, the input follows common modern subtractive and repetition rules. Variants used in historical sources and on some clock faces, such as IIII for 4, are not supported.

Does the date converter check that a date is valid?

No. The date field also works as a multi-value converter, so it converts each separated component as a number without checking month lengths or leap years.

What is the formula for an overlined Roman numeral?

Multiply its ordinary value by 1,000. For example, _V = 5 × 1,000 = 5,000. A group of overlined letters is evaluated using the same subtractive rules before multiplying by 1,000.
