    How to Use the Pythagorean Theorem Calculator

    For any right triangle, enter the measurements of two sides and leave both boxes for the unknown side empty. The two short perpendicular sides are a and b; the longest side, opposite the 90° angle, is the hypotenuse c. Select Calculate to solve the missing side and display the other triangle properties above the input form.

    Every side has two boxes: the first is a coefficient, and the box following the square-root symbol is the radicand. For example, to enter 2√5, type 2 in the first box and 5 in the square-root box. To enter a plain number like 4, type 4 in the first box and leave the radical box empty. Leave the coefficient box empty to enter √5. Use positive side lengths and a consistent unit of length.

    Pythagorean Theorem Formula

    The relationship between the sides of a right triangle is a² + b² = c². Rearrange the equation according to the missing side:

    • Hypotenuse: c = √(a² + b²).
    • Leg a: a = √(c² − b²).
    • Leg b: b = √(c² − a²).

    If one leg and the hypotenuse are known, the hypotenuse must be longer than the leg. Both legs must be strictly positive, and no three inconsistent side lengths can describe a right triangle.

    Worked Example: a = 2 and c = 2√5

    We know that a² = 4 and c² = 20. Then b² = c² − a² = 20 − 4 = 16, so b = 4. The other results are an area of 4 square units, a perimeter of approximately 10.472135955 units, and altitude h = 4√5/5 ≈ 1.788854382 units. The acute angles are approximately 26.565° and 63.435°.

    Angles, Area, Perimeter, and Altitude

    The result panel provides the two acute angles in decimal degrees, degrees–minutes–seconds (DMS), and radians. The lower-right angle is α = arctan(a / b); the upper-left angle is β = 90° − α.

    • Area: A = a × b / 2, measured in square units.
    • Perimeter: P = a + b + c, measured in the same linear units as the sides.
    • Altitude to the hypotenuse: h = a × b / c, the perpendicular segment from the right-angle vertex to side c.

    Frequently Asked Questions

    Can I enter two legs instead of the hypotenuse?

    Yes. If a and b are known, the calculator finds c with c = √(a² + b²). For example, a = 3 and b = 4 produce c = 5.

    How do I enter a length with a square root?

    To enter 3√2, type 3 in the first box and 2 in the box after √ for the chosen side. For √7, leave the first box empty and enter 7 in the radical box.

    Why does the calculator reject some measurements?

    A right triangle has two positive legs and a hypotenuse longer than either leg. If all three sides are supplied, they must satisfy a² + b² = c² within numerical rounding tolerance.

    Which units does the calculator use?

    The calculation does not assume a particular unit. All entered sides must use the same length unit (for example, meters or inches). Perimeter and altitude use that unit; area uses the corresponding squared unit.

    Are the displayed angles exactly rounded?

    The underlying calculations use floating-point precision. Displayed degrees and radians are rounded for readability, and exact radical forms are shown when they can be expressed reliably.
