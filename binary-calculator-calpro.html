How to Use the Binary Calculator

Enter two binary numbers (made up of 0s and 1s), choose addition, subtraction, multiplication, or division, and select Calculate. The answer appears at the top of the calculator in binary and decimal form. The two lower forms convert between the binary and decimal number systems. Each form also has its own Clear button.

What Is the Binary Number System?

Binary is a base-2 numbering system. Unlike decimal (base 10), which has ten digit symbols from 0 through 9, binary uses only 0 and 1. Each position corresponds to a power of 2. Moving one place to the left doubles the place value: 1, 2, 4, 8, 16, and so on.

Binary Arithmetic Formulas and Examples

Binary Addition

Add digits column by column from right to left. In binary, 1 + 1 = 10₂, so write 0 and carry 1 to the next column. Example: 1010₂ + 11₂ = 1101₂ (10 + 3 = 13 in decimal).

Binary Subtraction

Subtract digits from right to left. If you must subtract 1 from 0, borrow from the next available 1 to the left. Example: 1010₂ − 11₂ = 111₂ (10 − 3 = 7).

Binary Multiplication

Binary multiplication uses only four single-digit products: 0 × 0 = 0, 0 × 1 = 0, 1 × 0 = 0, and 1 × 1 = 1. Shift each partial product left as you move through the second operand. Example: 101₂ × 11₂ = 1111₂ (5 × 3 = 15).

Binary Division

Binary long division works like decimal long division. An exact division such as 1100₂ ÷ 11₂ = 100₂ corresponds to 12 ÷ 3 = 4. When a division is not exact, the calculator displays fractional binary and decimal digits. Parentheses indicate a repeating sequence, and an ellipsis indicates a truncated expansion. For example, 1010₂ ÷ 11₂ = 11.(01)₂, equivalent to 10 ÷ 3 = 3.(3) in decimal.

How to Convert Binary to Decimal

Multiply each binary digit by its corresponding power of 2, starting with 2⁰ at the rightmost digit, then add the contributions. For example:

10101010₂ = 170₁₀

(1 × 128) + (0 × 64) + (1 × 32) + (0 × 16) + (1 × 8) + (0 × 4) + (1 × 2) + (0 × 1) = 170.

How to Convert Decimal to Binary

Repeatedly divide the positive decimal integer by 2 and record each remainder. Read the remainders upward to obtain its binary representation. For example, 170 becomes 10101010₂. Zero converts to 0₂; a negative integer uses a leading minus sign followed by the magnitude's binary digits.

Results, Limits, and Number Representation

This calculator supports up to 64 binary digits per binary input and up to 15 decimal digits for decimal-to-binary conversion. It uses JavaScript BigInt for exact integer arithmetic rather than floating-point numbers, including values larger than JavaScript's ordinary safe-integer range. Intermediate addition or multiplication results can contain more than 64 bits.

Negative results use a leading minus sign, not two's-complement encoding. Two's complement depends on a specified bit width, which the reference calculator does not ask for. For non-terminating division, a fraction may be shown as repeating or abbreviated after a limited number of digits; the displayed integer quotient and remainder remain exact.

Frequently Asked Questions

What does 1010 mean in decimal?

1010₂ means 8 + 2, which equals 10₁₀.

What happens if I divide by zero?

Division by zero is undefined, so the calculator displays an inline error rather than a result.

Can I enter a binary number with spaces or other digits?

No. Enter only 0s and 1s (optionally prefixed with + or −); grouping spaces, the prefix 0b, commas, and other digits are not accepted.

Does the calculator accept binary fractions as inputs?

No. Inputs must be integers. Binary division can nevertheless produce a fractional result when the quotient is not a whole number.

Are the results fixed-width or two's-complement binary?

No. Results are written in ordinary signed binary notation without padding to a fixed number of bits.
