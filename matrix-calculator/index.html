How to Use the Matrix Calculator

Choose the row and column count for Matrix A and Matrix B (1 to 10 for each). Enter numbers in the cells; leave a cell blank to use zero. You can increase or decrease the dimensions using the arrow buttons. When a matrix is wider than its panel, scroll within the cell grid. You can also paste tab-separated matrix values from a spreadsheet into the grid.

Use Clear to empty all cells, All 0 for a zero matrix, All 1 for an all-ones matrix, and Random to fill cells with digits from 0 to 9. Use the operations inside either matrix panel for one-matrix calculations, or the green buttons underneath for two-matrix operations. The result is shown immediately below the buttons; use Copy To A or Copy To B to reuse it.

Matrix Operations and Formulas

Addition and Subtraction

Matrices must have identical dimensions. For a matrix entry in row i, column j, the sum and difference are (A ± B)ij = aij ± bij.

Matrix Multiplication

If A has m rows and n columns, and B has n rows and p columns, then AB is an m × p matrix. The entry at row i, column j is (AB)ij = Σk=1…n aikbkj. Order matters: AB generally differs from BA.

Transpose, Determinant, and Inverse

A transpose exchanges rows with columns: (AT)ij = aji. Determinants and inverses require a square matrix. For a 2 × 2 matrix A = [[a, b], [c, d]], det(A) = ad − bc. If the determinant is nonzero, A−1 = (1/det(A)) × [[d, −b], [−c, a]]. Larger determinants are calculated by Gaussian elimination; inverses use Gauss–Jordan elimination with pivoting.

Powers and Scalar Multiplication

For square matrices, A2 means A × A and A0 is the identity matrix. Negative integer powers require an invertible matrix (for example A−2 = A−1A−1). Multiplying a matrix by a scalar c multiplies every element: (cA)ij = c × aij. The power field accepts integer exponents from −100 to 100.

Worked Example

Suppose A = [[1, 2], [3, 4]] and B = [[5, 6], [7, 8]]. The sum is A + B = [[6, 8], [10, 12]], and AB = [[19, 22], [43, 50]]. The determinant of A is 1 × 4 − 2 × 3 = −2, so its inverse is [[−2, 1], [1.5, −0.5]].

Frequently Asked Questions

Why can’t I add matrices of different sizes?

Addition and subtraction combine matching entries, so both matrices must have exactly the same number of rows and columns.

Why is matrix multiplication rejected?

For AB to exist, A’s number of columns must equal B’s number of rows; the matrices do not need to be square.

Can a matrix have no inverse?

Yes. Only square, nonsingular matrices have an inverse. A matrix with a determinant of zero has no inverse; numerical calculations may also flag nearly singular matrices.

Are decimal results exact?

The calculator uses JavaScript floating-point arithmetic, and displays up to 12 significant digits. Very small rounding differences may occur, especially with ill-conditioned matrices or large powers.
