How to Use the Number Sequence Calculator

Choose the sequence type that matches your problem. For an arithmetic sequence, enter the first number, the fixed difference between terms, and the position n. For a geometric sequence, provide the first number, the common ratio, and the term position. For Fibonacci numbers, enter only the index n.

Select Calculate to display the sequence preview, the requested term, and the sum of terms through that position. Each result appears immediately above its corresponding form. Choose Save to download the exact result as a plain-text file. Clear empties that form.

Arithmetic Sequence Formula

An arithmetic sequence increases or decreases by the same amount d each time. The term at position n and the sum of the first n terms are:

an = a1 + (n − 1)d
Sn = n(a1 + an) / 2

Example: Start with 2 and add 5 repeatedly: 2, 7, 12, 17, ... . At position 20, a20 = 2 + (19 × 5) = 97. The sum of the first 20 terms is 20 × (2 + 97) / 2 = 990.

Geometric Sequence Formula

In a geometric sequence, multiply each term by the same ratio r. For first term a:

an = arn−1
Sn = a(1 − rn) / (1 − r), if r ≠ 1.
If r = 1, Sn = na.

Example: Starting from 2 with a common ratio of 5 produces 2, 10, 50, 250, ... . The 12th term equals 2 × 511 = 97,656,250, and the sum of the first 12 terms is 122,070,312. Decimal and negative inputs are supported.

Fibonacci Sequence Formula

The Fibonacci sequence begins with F0 = 0 and F1 = 1. Each subsequent term is the sum of the preceding two:

Fn = Fn−1 + Fn−2 for n ≥ 2.
F0 + F1 + … + Fn = Fn+2 − 1.

Example: F10 = 55. Adding every Fibonacci number from F0 through F10 gives 143. Unlike the other two calculators, the Fibonacci index is zero-based: F0 is the 0th term.

Understanding the Results

The sequence line is a preview of the pattern, not necessarily the complete list of requested terms. The value is the term at index n, and the sum adds all terms from the starting index to that term. Values are calculated with exact decimal or integer arithmetic; extremely long results are abbreviated in the on-screen display but remain complete in the downloadable result.

Frequently Asked Questions

Can the common difference or ratio be negative?

Yes. A negative difference makes arithmetic terms decrease. A negative geometric ratio alternates the signs of successive terms. A zero ratio is also calculated as a first term followed by zeros.

What happens when a geometric ratio equals 1?

Every term equals the first number, so the sum is simply the first number multiplied by the count of terms. The calculator handles this case directly without dividing by zero.

Why does Fibonacci allow n = 0?

The common Fibonacci definition starts at F0 = 0, so n = 0 is a valid input. Arithmetic and geometric sequences on this page start with n = 1.

What are the input limits?

The index can be as large as 1,000. For arithmetic and geometric inputs, enter ordinary signed decimals using no more than 22 digits total and up to 12 digits after the decimal point. These limits help keep calculations responsive in a browser.
