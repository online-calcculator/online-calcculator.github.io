How to Use the Exponent Calculator

Enter values in any two of the three fields: base, exponent, and result. Leave the value you want to calculate blank, then select Calculate. The answer and a short explanation appear directly above the form. Select Clear to start over.

For powers of Euler’s number, select use e as base. This enters the constant e (approximately 2.718281828459045). Use a decimal such as 0.5 for a fractional exponent; ordinary fraction strings such as 1/2 are not supported.

Exponent Formulas

Exponentiation is written as an = y, where a is the base, n is the exponent, and y is the result. For a positive integer n, exponentiation multiplies the base by itself n times.

Worked Examples

Calculate a power: 25 = 2 × 2 × 2 × 2 × 2 = 32.

Find an exponent: If 3n = 81, then n = ln(81) / ln(3) = 4.

Find a base: If a3 = 125, then a = 1251/3 = 5. For a2 = 25, both a = 5 and a = −5 satisfy the equation; the calculator shows the principal root and notes the other solution.

Exponent Rules and Special Cases

  • Negative exponents: a−n = 1/an for a ≠ 0.
  • Zero exponent: a0 = 1 for a ≠ 0; 00 is treated as indeterminate here.
  • Fractional exponent: a1/2 is the square root of a for a ≥ 0.
  • Multiplying powers: am × an = am+n.
  • Power of a power: (am)n = amn wherever both sides are defined in the real-number domain.
This calculator uses real-number arithmetic. Negative bases are supported for integer exponents; non-integer powers of negative bases and complex-number results are outside its scope. When a mathematical inverse is not unique, the calculator identifies the ambiguity instead of assigning an arbitrary answer.

Frequently Asked Questions

Can I use the number e as the base?

Yes. Select use e as base, or type e in the base field. For example, e1 ≈ 2.718281828459.

Can I calculate a negative exponent?

Yes. For example, 2−3 = 1/8 = 0.125. The base must be nonzero.

Why might there be two valid bases?

An even integer exponent removes the sign of a real base. For example, both 42 and (−4)2 equal 16.

What is the difference between a root and an exponent?

A root reverses exponentiation. Solving a3 = 8 for a means finding a cube root of 8.

Why is a calculation rejected?

Three filled fields, fewer than two filled fields, division by zero, non-unique inverse relationships, complex-valued cases, and numbers outside the browser’s supported range can prevent a single real-number answer.
