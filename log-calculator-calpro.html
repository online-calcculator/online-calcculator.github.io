How to Use the Log Calculator

Enter any two known quantities in logb(x) = y: the argument x (top input), the base b (bottom input), or the logarithm y (right input). Leave exactly one field empty, then select Calculate. The answer and a corresponding exponential equation appear above the form. Select Clear to empty all three inputs, or save in the result bar to download the result as a text file.

Logarithm Formulas

A logarithm answers the question: “What power of the base produces the argument?” Its exponential equivalent is by = x. You can rearrange this relationship to solve for any one of the three quantities.

Basic Logarithm Rules

For positive arguments u and v, with a valid common base b:

  • Product: logb(uv) = logb(u) + logb(v).
  • Quotient: logb(u/v) = logb(u) − logb(v).
  • Power: logb(uk) = k · logb(u).
  • Special values: logb(1) = 0 and logb(b) = 1.

Frequently Asked Questions

Can the logarithm result be negative?

Yes. For instance, log10(0.01) = −2, because 10−2 = 0.01. The argument remains positive even when the logarithm is negative.

Why can't the base be 1 or a negative number?

For real logarithms, the base must be positive and different from 1. A base of 1 cannot produce values other than 1; a negative base does not define a logarithm for every positive real argument.

Why can't I enter zero or a negative argument?

The real logarithm logb(x) is defined only for x > 0. This calculator works with real values, not complex logarithms.

Can I calculate the base when y = 0?

No unique base can be calculated. If x = 1, every valid base produces y = 0. If x is not 1, there is no solution, since b0 = 1 for all valid bases.

Does the calculator support scientific notation?

Yes. Type entries such as 1e6 or 2.5e-4. A standalone e is also recognized as Euler's number in the base input.
