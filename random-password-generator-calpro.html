How to Use the Random Password Generator

Enter your preferred password length (4 to 5,000 characters), or move the slider between 4 and 100. Choose lowercase letters, uppercase letters, numbers, and/or symbols. Tick the exclusion options to remove characters that are difficult to distinguish or bracket characters. The generated password appears above the settings panel and updates whenever an option changes.

  1. Choose the character sets accepted by the service where you will use the password.
  2. Increase the length for greater resistance to guessing. For most accounts, consider at least 12–16 randomly generated characters if permitted.
  3. Use Generate or Regenerate to create a new password.
  4. Select Copy Password to copy it. Paste it into a reputable password manager or the account registration field.
  5. Select Save Settings to store only your options on this device; the password itself is never saved by the generator.

Password Entropy Formula

Entropy measures the size of the space from which a password is selected. When each position can independently use any of N characters and the length is L, the standard estimate is H = L × log2(N) bits. This generator guarantees at least one character from every selected set, so it measures the slightly smaller, exact number of eligible passwords instead.

With selected groups of sizes n1, n2, ..., let N be their sum. Using inclusion–exclusion, the number of valid passwords with repeats allowed is V = ΣS (−1)|S|(N − Σi∈S ni)L, where S ranges over subsets of the selected groups. Entropy is then H = log2(V) bits. With no repeated characters, replace each power xL by the falling factorial x!/(x−L)! (or zero when x is smaller than L). The generator draws uniformly from this eligible space using cryptographically secure rejection sampling.

Worked Example

With 12 characters drawn from lowercase, uppercase, and digits, the total pool has 26 + 26 + 10 = 62 characters. The ordinary independent-draw estimate is 12 × log2(62) ≈ 71.5 bits. Requiring at least one of each selected type removes some possible strings, so the displayed exact entropy is slightly lower.

Frequently Asked Questions

Does the generator send or store my password?

No. Password generation runs entirely in your browser and uses its cryptographically secure random number generator. The only optional local storage contains your chosen length and checkbox settings, not generated passwords.

What does “No Repeated Characters” do?

Each character can appear at most once. This also caps the maximum possible length to the number of characters remaining after exclusions. If you request more unique characters than the selected sets contain, the calculator displays an error instead of producing a shorter password.

Why exclude ambiguous characters and brackets?

Some characters resemble each other in common fonts, while some websites restrict brackets or punctuation. Excluding them helps compatibility but shrinks the possible character pool; consider increasing length when exclusions are enabled.

Why might the entropy differ slightly from other password generators?

Many generators use the approximate L × log2(N) formula even when they require every selected character type to appear. Here the displayed number accounts for that requirement and for the no-repeats setting, so it can be slightly lower.

Does a strong meter mean my password is safe everywhere?

Not necessarily. Use a different password for every account, enable multifactor authentication, avoid sharing credentials, and store passwords securely in a password manager.
