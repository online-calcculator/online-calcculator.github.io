How to Use the Quadratic Formula Calculator

Enter the coefficients a, b, and c from an equation in the form ax2 + bx + c = 0. The value of a cannot be zero. You may enter integers, decimals, negative numbers, or fractions such as 3/4 and -5/2.

  1. Rewrite the equation with zero on the right.
  2. Enter each coefficient with its sign.
  3. Choose Calculate to see the roots, discriminant, and substitution steps above the form.
  4. Open Show graph to see the parabola and real x-intercepts; select save to export the calculation as text. Clear empties the inputs and hides the result.

Quadratic Formula and Discriminant

For a quadratic equation where a ≠ 0, the solutions are given by x = (−b ± √(b2 − 4ac)) / (2a). The discriminant is Δ = b2 − 4ac.

DiscriminantType of solution
Δ > 0Two distinct real roots
Δ = 0One repeated real root
Δ < 0Two complex conjugate roots, with no real x-intercepts

Worked Example: One Repeated Root

For x2 + x + 1/4 = 0, use a = 1, b = 1, and c = 1/4. Then Δ = 12 − 4(1)(1/4) = 0. The equation has a repeated root: x = −1/2 = −0.5.

Worked Example: Two Distinct Real Roots

For x2 − 3x + 2 = 0, Δ = (−3)2 − 4(1)(2) = 1. Using the quadratic formula gives x = 1 or x = 2.

Worked Example: Complex Roots

For x2 + 1 = 0, Δ = −4. Its solutions are x = i and x = −i, where i2 = −1. The parabola does not intersect the real x-axis.

Frequently Asked Questions

Can the calculator use fractions and negative coefficients?

Yes. Enter a fraction using a slash, such as 1/4, or use values such as −2, 0.75, or 2e-3. Do not put a variable in a coefficient box.

What if the discriminant is negative?

The equation has two complex conjugate solutions. They contain an imaginary component written using i, the square root of −1.

What happens when a = 0?

The quadratic formula is undefined when a = 0 because the denominator is 2a. A zero value for a produces a linear or constant equation instead; this tool asks for a nonzero a.

Are the displayed decimal roots exact?

Where exact rational roots can be recognized, the calculation may display their fractional form. Otherwise, the numeric roots are rounded for display. An exact irrational solution can have infinitely many decimal digits.
