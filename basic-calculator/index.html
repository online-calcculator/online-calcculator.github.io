How to Use the Basic Calculator

Click the number keys and one of the operation keys (+, −, ×, ÷), then enter another number and press =. The current input or result appears in the blue display, while the completed expression appears above it. Recent calculations appear directly below the keypad.

Back removes the last digit, AC clears the current calculation and visible history, and ± changes the sign. Ans recalls the most recent computed result. EXP enters powers of ten using scientific notation; for example, 2 EXP 3 represents 2 × 103 = 2,000. RND inserts a random decimal from 0 (inclusive) to 1 (exclusive).

Memory Buttons

M+ adds the displayed value to calculator memory; M- subtracts it; MR recalls the stored value. AC clears the working expression but preserves memory until you refresh the page. To set memory to zero without refreshing, recall it with MR and use M- on that recalled value.

Keyboard Shortcuts

Use the number keys, decimal point, +, −, *, and /. Press Enter or = to calculate, Backspace to remove the last digit, and Escape or Delete for AC. The E key enters scientific notation, and R produces a random number.

Understanding the Results

The blue display shows the value you are entering or the computed answer. After pressing =, the full expression appears above the result, and the calculation is saved in the small history area below. Long decimal results are rounded for readable display; calculations use JavaScript floating-point arithmetic internally.

Frequently Asked Questions

Can I calculate with decimals and negative numbers?

Yes. Press the decimal point once within a number and use ± to switch between positive and negative values.

What happens if I divide by zero?

Division by zero displays an error rather than an invalid answer. Press AC or enter a new digit to start another calculation.

What does EXP mean?

EXP stands for exponent in base-10 scientific notation. For instance, entering 6 EXP 2 represents 6 × 102, which equals 600. Press ± while editing the exponent to enter a negative exponent.

Does the calculator follow the order of operations?

Yes. In expressions with multiple operators, multiplication and division are evaluated before addition and subtraction, working from left to right within each priority level.

Is the random number predictable?

RND uses the browser's pseudo-random number generator and is intended for everyday calculations, not security or cryptography.
