How to Use the Random Number Generator

Choose the basic generator for one whole number or select the comprehensive version to create up to 999 values. Enter the lower and upper limits, choose whether results should be integers or decimals, and select Generate. The result appears directly above the form you used. Clear empties that form and removes its previous result.

Generate several numbers

When you request two or more values, extra controls let you allow repeated values or require a unique set. You can also leave the numbers in random order, sort them from smallest to largest, or sort them from largest to smallest. If the range is too narrow for the requested number of unique results, the calculator displays a validation message rather than repeating values.

How Random Numbers Are Calculated

For an inclusive integer interval from L through U, there are U − L + 1 possible values. An unbiased uniform draw gives each integer a probability of 1 / (U − L + 1). The generator uses exact integers and rejection sampling to avoid the modulo bias that can occur when generating random numbers across arbitrary-sized intervals.

For decimals, precision means the number of digits after the decimal point. The calculator converts limits to an exact grid with spacing 10−p, where p is the chosen precision. It rounds the lower limit upward to the first valid grid point and the upper limit downward to the last valid grid point, then samples uniformly from that finite set. This avoids ordinary JavaScript floating-point rounding errors.

Worked Examples

If the limits are 1 and 10, any of the ten integers is possible, including both endpoints. Each has a 1-in-10 chance per draw. If the decimal limits are 0.2 and 1.2 with a precision of 1 digit, the available values are 0.2, 0.3, 0.4, and so on through 1.2: eleven equally likely values.

Understanding the Results

Each draw is independent when duplication is allowed, so an earlier result does not make a particular number more or less likely on the next draw. Disabling duplication samples without replacement and makes every returned value distinct. Sorting changes only the display order, not which values were selected.

Frequently Asked Questions

Are the lower and upper limits included?

Yes, in integer mode. In decimal mode, a limit is included if it is exactly representable at the selected number of decimal places; otherwise the nearest allowable value inside the requested interval is used.

Can I generate very large integers?

Yes. The basic form accepts integer bounds containing up to 5,000 digits. The comprehensive form supports bounds containing up to 999 digits, up to 999 results per request, and up to 999 digits after the decimal point.

What happens when I ask for too many unique values?

If you turn off duplication and request more numbers than the range can contain, the calculator shows an error. Increase the interval, reduce the quantity, or allow duplicates.

Is the result suitable for passwords or security?

The calculator uses the browser's Web Crypto random-number service where available and falls back to standard pseudorandom generation in older environments. It is intended for everyday sampling, teaching, and simulations, not as an audited security or cryptographic key-generation tool.

Does it require an internet connection?

No. After the HTML and stylesheet are available locally, all values are generated in the browser without sending the input to a server.
