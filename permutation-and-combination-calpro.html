How to Use the Permutation and Combination Calculator

Enter the total number of distinct items in the set as n, and the number you want to select as r. Select Calculate to see both counts at once. The results update in the green-headed panel to the right of the inputs on wider screens and below the inputs on narrow screens.

Use Clear to erase both values and hide the previous results. The small save control in the result header downloads the current calculation as a text file.

Permutation and Combination Formulas

Permutations: order matters

When each item can be used at most once, the number of ordered selections is nPr = n! / (n − r)!. Here, ! represents factorial: for example, 5! = 5 × 4 × 3 × 2 × 1.

Combinations: order does not matter

The number of unordered selections is nCr = n! / [r! × (n − r)!]. Each group of r items has r! possible arrangements, so combinations count those arrangements only once.

Key difference: Selecting first place and second place is a permutation. Selecting two teammates without assigned roles is a combination.

Worked Example: Select 2 of 6 Items

For a set of six distinct items with a subset of two, permutations equal 6 × 5 = 30. Combinations equal (6 × 5) ÷ (2 × 1) = 15. These are the default results shown when the page loads.

Input Rules and Interpretation

Inputs must be nonnegative whole numbers with 0 ≤ r ≤ n ≤ 10,000. This implementation uses arbitrary-precision integer arithmetic, so it does not round large counts to floating-point approximations. Very large results may have thousands of digits.

This calculator assumes that each item is distinct and can be selected only once. It does not calculate arrangements with replacement (such as drawing the same item multiple times).

Frequently Asked Questions

When should I use a permutation instead of a combination?

Use a permutation when choosing the same items in a different order changes the outcome, such as assigning ranked places. Use a combination when only membership matters, such as forming a committee.

What happens when r = 0?

There is exactly one way to select no items: the empty selection. Therefore, both nP0 and nC0 equal 1.

What happens when r = n?

All n items can be arranged in n! different orders, so nPn = n!. There is only one way to select all n items without regard to order, so nCn = 1.

Why do permutations always count at least as many outcomes as combinations?

Each unordered group of r items corresponds to r! different orders. As a result, nPr = nCr × r!.
